# מערכת קביעת פגישות ייעוץ

מבקרים באתר בוחרים סוג פגישה, יום ושעה פנויים, ומשאירים שם וטלפון. הבקשה נשמרת במסד נתונים
ומחכה לאישור. ירין מאשר, דוחה או מציע מועד אחר באזור הניהול (`/admin`), והמבקר רואה את הסטטוס
בדף פרטי (`/booking-status?id=...&t=...`).

## איך זה בנוי

| חלק | איפה | מה הוא עושה |
|---|---|---|
| אשף ההזמנה | `src/pages/booking.tsx` | בחירת שירות ← מועד ← פרטים ← אישור ושליחה |
| דף סטטוס | `src/pages/booking-status.tsx` | ממתין / מאושר / נדחה / הוצע מועד חלופי. אפשר לאשר הצעה או לבטל |
| אזור ניהול | `src/pages/admin.tsx`, `src/components/admin/` | התחברות, רשימת בקשות, אישור/דחייה/הצעת מועד, שעות זמינות וימים חסומים |
| שרת (API) | `functions/api/` | Cloudflare Pages Functions. כל הבדיקות נעשות כאן שוב, גם אם הדפדפן כבר בדק |
| מסד נתונים | Cloudflare D1, הטבלאות ב-`migrations/` | בקשות, סטטוסים, שעות פעילות, ימים חסומים |
| שירותים | `src/data/booking.ts` | רשימת סוגי הפגישות. **מחיר ומשך מוצגים רק כשממלאים אותם** |
| חישוב מועדים | `src/lib/booking-time.ts` | משבצות לפי שעון ישראל (כולל שעון קיץ), ובדיקות לטופס |

### אבטחה והגנה מספאם

- הסיסמה למנהל נשמרת רק כ-Secret ב-Cloudflare. היא לא נמצאת בקוד ולא נשלחת לדפדפן.
- ההתחברות שומרת עוגייה חתומה (HttpOnly, Secure, SameSite=Strict) ל-12 שעות. אחרי 5 סיסמאות שגויות הכניסה ננעלת ל-15 דקות.
- המבקר רואה רק את הבקשה שלו, בעזרת קוד פרטי שבקישור. במסד נשמר רק ה-hash של הקוד.
- המסד עצמו חוסם הזמנה כפולה של אותה משבצת, גם אם שני אנשים שולחים באותה שנייה.
- אי אפשר לבחור מועד שעבר, יום חסום או שעה שמחוץ לשעות הפעילות.
- נגד ספאם: שדה נסתר שרק בוטים ממלאים, דחייה של שליחה מהירה מדי, עד 5 בקשות בשעה מאותה כתובת IP, ועד 2 בקשות פתוחות לכל מספר טלפון.
- הודעת "נשמר" מופיעה רק אחרי שהשרת אישר שהבקשה נשמרה.

### מה המערכת **לא** עושה (עדיין)

- **אין שליחת הודעות אוטומטית.** ירין לא מקבל התראה על בקשה חדשה, וצריך להיכנס ל-`/admin`. אחרי אישור או דחייה יש כפתור שפותח וואטסאפ עם הודעה מוכנה ללקוח, אבל השליחה עצמה ידנית.
- כל פגישה תופסת משבצת אחת. את אורך המשבצת קובעים באזור הניהול.

## הפעלה באתר החי (פעם אחת)

> שלבים 1–5 כבר בוצעו ב-3.10.2026 (מסד `bonim-booking`, הסודות הוגדרו). הם כאן לתיעוד, או למקרה שצריך להקים מחדש.
> להחלפת סיסמת המנהל מריצים שוב רק את שלב 3.

צריך להריץ את הפקודות בטרמינל, מתוך תיקיית הפרויקט.

1. **יצירת מסד הנתונים:**
   ```
   npx wrangler d1 create bonim-booking
   ```
   בתוצאה יופיע `database_id`. מעתיקים אותו לקובץ `wrangler.toml`, במקום `REPLACE_WITH_D1_DATABASE_ID`.

2. **יצירת הטבלאות:**
   ```
   pnpm db:migrate:remote
   ```

3. **הגדרת סיסמת מנהל** (לפחות 10 תווים. בוחרים סיסמה חזקה ושומרים אותה):
   ```
   npx wrangler pages secret put ADMIN_PASSWORD --project-name bonim-mikir-lekir
   ```

4. **הגדרת מפתח התחברות** (מחרוזת אקראית. הפקודה הראשונה מייצרת אותה):
   ```
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   npx wrangler pages secret put SESSION_SECRET --project-name bonim-mikir-lekir
   ```
   מדביקים את המחרוזת כשהפקודה השנייה מבקשת.

5. **פרסום האתר:**
   ```
   pnpm upload
   ```

6. **בדיקת שעות:** השלב הקודם כבר טען את שעות הפעילות שמופיעות באתר (ראשון–חמישי 08:30–20:30,
   שישי 07:00–13:00, שבת סגור, פגישות של 90 דקות). כדי לשנות אותן נכנסים ל-
   `https://bonim-mikir-lekir.pages.dev/admin`, עוברים ללשונית **זמינות** ולוחצים **שמירת שינויים**.
   ערבי חג לא מזוהים אוטומטית. אפשר לחסום אותם (את כל היום) בלשונית **זמינות** → **ימים חסומים**.

## עריכת שירותים, מחירים ומשך

פותחים את `src/data/booking.ts`. לכל שירות יש:

- `name`, `description` – מה שמוצג למבקר
- `durationMinutes` – משך הפגישה בדקות. `null` = לא מוצג
- `price` – מחיר בש"ח כולל מע"מ. `null` = לא מוצג

אחרי שינוי מריצים `pnpm upload`. לא מוחקים `id` של שירות שכבר יש עליו בקשות. את המשבצות
עצמן (אורך, התראה מראש, כמה ימים קדימה) מגדירים באזור הניהול.

## פיתוח מקומי

```
# פעם אחת: סודות לבדיקה מקומית (הקובץ מוחרג מ-git)
echo ADMIN_PASSWORD=local-test-password-123 > .dev.vars
echo SESSION_SECRET=<מחרוזת אקראית של 32+ תווים> >> .dev.vars
pnpm db:migrate:local

# בנייה והרצה עם ה-API ומסד נתונים מקומי
pnpm core:build
pnpm preview:full        # http://localhost:8788
```

`pnpm dev` (Vite) מריץ רק את האתר, בלי ה-API.

## בדיקות

- `pnpm test:unit` – חישוב משבצות, שעון ישראל ושעון קיץ, ובדיקות הטופס (`tests/`)
- `pnpm lint` – ESLint, TypeScript (כולל `functions/`), Knip
- `pnpm build` – מריץ את שתיהן ואז בונה
